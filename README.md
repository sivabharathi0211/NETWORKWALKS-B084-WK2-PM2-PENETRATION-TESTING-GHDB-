# NETWORKWALKS-B084-WK2-PM2-PENETRATION-TESTING-GHDB-

📌 Project Overview

* This project is part of the Networkwalks Cybersecurity & Ethical Hacking Internship (Week 2 - Project Module 2). It describes how the Google Hacking Database (GHDB) can be used for footprinting and reconnaissance — locating publicly exposed devices and files using advanced Google search operators (dorks), without directly interacting with the target.

🎯 Objective

* Learn how Google Dorking is used for passive reconnaissance
* Use GHDB / Exploit-DB to find real-world dorks
* Identify exposed devices and files that are unintentionally public

📋 Tasks

Task 1: Web Camera Reconnaissance Used Google Dorks to identify publicly indexed webcam pages. Documented the search queries and findings.

Task 2: Mathematics PDF Reconnaissance Used Google Dorks to find publicly available mathematics PDF resources. Documented the search queries and findings.

🧠 Key Takeaway

Reconnaissance is the first step of any attack and penetration testing, and it can be done entirely through Google without ever touching the target. The same dorks used by attackers can be used by organizations to find and fix their own exposures.
